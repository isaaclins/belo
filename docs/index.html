One answer, or many

Pick once, at the start. One answer: Belo names the best match. Many answers: each label gets its own yes or no.

Made up numbers. Pictures with no label sit training out.

Hold to teach

Tap to teach one picture. Hold and they keep coming, up to 60. Try it.

2 to 12 pictures a second, your pick. If the disk falls behind, pictures get dropped.

Find your own objects with real boxes

Choose Detect objects when you start a project. Draw boxes around the things you care about, press Train, then use the camera. Belo can find your custom objects and draw a box around each one. It is not limited to a list of common objects someone else chose.

About 50 to 200 boxes for each label usually helps. Training on desktop is recommended.

Borrowed eyes, a small brain of your own

Eyes

MobileNet v1, 224 pixels

A ready made picture reader, built in. It turns pictures into clues, and never phones home.

Brain

100 units, seconds per run

The only part that learns your labels. That is why training takes seconds, not hours.

Engine

TensorFlow.js, graphics card first

Graphics card if possible, processor if not. No server, no API key, no sign up.

Undo

One spare copy, one button

Belo copies the old model before retraining itself. One button brings it back.

A project is a folder you can open

A plain folder named Project.belo. Same on Mac, Windows and Linux. Open it, copy it, back it up.

Belo writes a temp file and renames it, so a crash cannot leave half a file. No model export yet.

  • One small file holds labels, pictures and settings.
  • Deleting asks first, and only ever touches real projects.
  • On iPhone, moving projects means a device backup for now.

Get it

Download Belo.
Free and open.

Pick your machine. Every installer is built by GitHub Actions from the tagged source, and each new version keeps the same links.

macOS

Apple Silicon, macOS 10.15 or newer

Download the .dmg

The build is not signed by Apple yet. The first time, right click Belo in Applications and choose Open, then confirm. A double click alone will be blocked.

Windows

64 bit, Windows 10 or newer

Download the installer

Prefer an msi? Belo-windows-x86_64.msi

The build is not signed yet, so SmartScreen may warn you. Choose More info, then Run anyway.

Linux

x86_64, needs WebKitGTK 4.1

Download the AppImage

On Debian or Ubuntu: Belo-linux-x86_64.deb

Mark the AppImage executable before the first run. The camera depends on your system, and Linux is the least tested.

See every file in the latest release

Or build it from source

The installers come from this same source. If you would rather build it yourself, you need Node 20, Rust 1.77 and the Tauri 2 system packages.

git clone https://github.com/isaaclins/belo.git
cd belo
npm install
npm run tauri build
